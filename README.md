# Sistema de Gestión de Infracciones de Tránsito

Proyecto Final de Ingeniería en Sistemas y Computación - Universidad Dominicana O&M (2025)

## ¿Qué hace?
Automatiza el registro, consulta y seguimiento de infracciones de tránsito.

## Tecnologías
- C# / .NET
- JavaScript, HTML/CSS
- SQL Server
- APIs REST / Servicios Web

## Funcionalidades
- Registro de infracciones con validaciones
- Consulta y seguimiento de registros
- Base de datos con integridad y trazabilidad
